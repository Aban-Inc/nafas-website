# Nafas documentation

Nafas.Observability is a self-hosted, embeddable observability dashboard
for ASP.NET Core: logs, metrics, traces, and alerts, captured
automatically from what your app already produces, with zero external
dependencies.

If you're new here, start with [Why Nafas](/docs/getting-started/why-nafas)
for the pitch, or jump straight to the
[Quick start](/docs/getting-started/quick-start) if you already know you
want it.

## Sections

- **Getting Started**: why Nafas exists, the two-line integration, and
  what you need to run it.
- **How It Works**: what gets captured automatically, and a tour of the
  internals for anyone evaluating this beyond the quick start.
- **Configuration**: every `AddNafasServer` option, and the dashboard's
  security default.
- **Deployment**: running multiple instances, and reaching WinForms/WPF/
  console apps with `Nafas.Observability.Server`.
- **Alerting**: threshold/absence rules and webhook delivery.
- **Contributing**: repository layout, local development, project status,
  and license.
